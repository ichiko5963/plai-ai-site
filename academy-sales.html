PAIN

こんな状態、
ありませんか？

  • AIに毎回同じ説明をしている。ChatGPT を毎日使っているのに、前回の答えが活かされず、毎回ゼロから自分の事業を説明している。
  • 情報がツールごとにバラバラ。Notion / Slack / Gmail / Drive — どこに何があるか、自分でも分からなくなっている。
  • 自動化したいが、何から手をつけるか分からない。ツールはたくさんあるが、自分の業務にどう接続するかの設計図がない。
  • 採用するほどの予算はない。だが今のままだと、自分が倒れた瞬間に事業が止まる。一人で抱え込んでいる感覚がある。
  • AIに任せたいが、結果が信用できない。出力の質にムラがあり、確認に時間がかかり、結局自分でやり直している。
  • 新しいAIに置いていかれそうで怖い。毎週のように新しいツールが出る。どこまでキャッチアップすればいいのか分からない。
  • 過去にAIスクールで挫折した。動画を観るだけ、抽象論ばかり。自分の事業で動くものは一つも作れなかった。

3つ以上当てはまったあなたへ。
このスクールは、まさにあなたのためのものです。

SOLUTION

答えは、
"AI社員" を作ること。

AI を "使う" のをやめて、"雇う" に変える。

AI社員とは、特定の役割（営業 / リサーチ / 経理 / 広報 / 採用 など）に特化したコンテキストを背負わせた 専用のAIエージェント のこと。一度作れば、同じ品質のアウトプットを再現性高く返してくれます。

AI社員チームを組めば、創業者1人で5〜10人分の業務を回せます。雇用コストはゼロ、24時間稼働、退職リスクもない。

そして、その全ての鍵が「第二の脳（セカンドブレイン）」。自分の判断基準・事業情報・過去の意思決定をローカルに蓄積し、AI社員にコンテキストとして渡す。これができれば、AIは「賢いがあなたを知らないツール」から「あなたの分身」に変わります。

FAQ

よくあるご質問

プログラミング未経験ですが受講できますか？

大丈夫です。Claude Code / Hermes Agent は対話で動かせます。コードを「書く」のではなく「指示する」のが本講座の目的です。

受講に必要な時間はどれくらいですか？

カリキュラムは合計15時間以上の動画です。週6〜8時間で約8週間。集中して取れる方は2〜3週間で完走される方もいます。

ベーシックとスタンダードの違いは？

ベーシックは買い切り教材で質問サポートなし。スタンダードは質問サポート ＋ 2026年中の継続更新カリキュラムが含まれます。受講生の8割以上がスタンダードを選ばれます。

プレミアムプランの「丸投げ」とは具体的に何をしてくれますか？

PLai 側のチームがあなたの事業をヒアリングし、必要なAI社員（営業／リサーチ／経理など）と Obsidian Vault（第二の脳）を構築してお渡しします。完成後3ヶ月の伴走付き。

AIを使ったことがありません。

STEP 1 の初回で ChatGPT / Claude の使い分けから扱います。AIを毎日使う人と未経験者で同じスタートラインを作ります。

Mac / Windows どちらでも受講できますか？

どちらでも対応可能です。環境構築テンプレを両方用意しています。

法人での申込は可能ですか？

可能です。法人プラン（2,980,000円〜・税抜）を別途用意しています。部署別カスタム／複数名研修／セキュリティ設計まで対応します。

返金保証はありますか？

受講開始から14日以内であれば全額返金いたします（プレミアム・法人プランは個別契約）。

動画はいつまで視聴できますか？

視聴期限はありません。買い切り後、永年視聴できます。スタンダード以上は2026年中の更新分も追加料金なしで視聴できます。

可能です。決済プラットフォームの分割払い（3回／6回／12回）に対応しています。

スタンダード以上は、新ツール解禁時の追加カリキュラムが追加料金なしで配信されます。2026年中、月1回以上のペースで更新予定です。
