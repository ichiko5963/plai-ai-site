FAQ

よくあるご質問

プログラミング未経験ですが受講できますか？

大丈夫です。Claude Code / Hermes Agent は対話で動かせます。コードを「書く」のではなく「指示する」のが本講座の目的です。

受講に必要な時間はどれくらい？

合計15時間以上の動画。週6〜8時間で約8週間。集中すれば2〜3週間で完走される方もいます。

ベーシックとスタンダードの違いは？

ベーシックは買い切りで質問サポートなし。スタンダードは質問サポート＋2026年中の継続更新カリキュラムが含まれます。

プレミアムの「丸投げ」とは？

PLai側があなたの事業をヒアリングし、必要なAI社員とObsidian Vault（第二の脳）を構築してお渡しします。完成後3ヶ月の伴走付き。

分割払いは可能ですか？

可能です。決済プラットフォームの分割払い（3回／6回／12回）に対応しています。

動画はいつまで視聴できますか？

視聴期限はありません。買い切り後、永年視聴できます。スタンダード以上は2026年中の更新分も追加料金なしで視聴できます。

過去にAIスクールで挫折しました。

多くの受講生が同じ経験者です。本講座は「観るだけ」では終わらない設計（毎章ワーク＋プロンプト即流用）で抽象論を排しています。
