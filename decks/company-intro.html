THE PROBLEM

多くの企業で、知識は
属人化し、失われている。

毎日生まれる議論・判断・知見。
その大半が、誰の頭の中にも残らないまま消えています。

ABOUT

PLaiは、企業の「知的資産」を構造化する会社。

会話・判断・成果物を、AIで再利用できる資産に。

会議・顧客対応・SNS運用・営業活動の中で生まれる膨大な情報を、属人化のまま失わせない。AIと組み合わせて、企業の知的資産を蓄積・活用できる仕組みをつくります。

「プロンプトは一時的、構造は永続的」。これが、PLaiの基本思想です。

PRINCIPLES

PLaiを動かしている、3つの原則。

01 MEMORY FIRST

会話と成果物を資産に変える

AIが過去を踏まえて動く設計。記憶を捨てない、捨てさせない。

02 CONTEXT NATIVE

プロンプトではなく構造で動かす

AIが迷わない構造を先に置き、実行精度を底上げします。

03 OPEN LEARNING

学びの入口を無料で広げる

知識の格差をテクノロジーで埋める。AirCleの根底にある思想。

PRINCIPLE 01 — MEMORY FIRST

AIに「記憶」を持たせる。
毎回ゼロから始めない。

蓄積型のAIに変える。

ChatGPTを開いて質問→閉じる、では昨日のやりとりは何も残らない。PLaiが構築するAIは、過去の会話・成果物・判断履歴を全て参照しながら動きます。

  • Obsidian Vaultによる永続記憶
  • CLAUDE.mdでの永続指示書
  • 過去の意思決定の出典付き提示

PRINCIPLE 02 — CONTEXT NATIVE

プロンプトではなく、構造で動かす。

AIが迷わない設計を、先に置く。

毎回「TypeScriptで書いて」「日本語でコメント」と説明する必要がない世界へ。AIの動き方を構造で先取りすれば、出力精度は一気に上がります。

  • CLAUDE.md による役割・スタック定義
  • SKILL.md による作業手順の標準化
  • Plan Mode による事前設計

PRINCIPLE 03 — OPEN LEARNING

学びの入口を、無料で広げる。

AIの恩恵を、誰でも受けられる世界に。

環境がない、お金がないから始められない人がいなくなるように。無料セミナー、学生コミュニティ、オープンな学習コンテンツを通じて、知識の格差を埋め続けます。

  • AirCle — 累計9,000名のAIコミュニティ
  • OpenClaw — 実践型AI学習プログラム
  • 無料イベント・記事の継続発信

SECTION 01

Mission &
Vision.

私たちが、何のために存在しているか。

MISSION

人生を夢中でplayする人を、1人でも増やす。

AIで「やりたいこと」に集中できる世界へ。

AIが当たり前になった時代に、テクノロジーは夢を叶える道具になる。事業を前に進めたい人、学びたい人、発信したい人が、自分の可能性を最大化できる環境をつくります。

誰もがAIの力を借りて、自分のやりたいことに集中できる世界。それが私たちの目指す未来です。

VISION

AIを学びたい人が、無料で学べる世界をつくる。

「お金がないから学べない」をなくす。

環境がないから始められない。そんな障壁をAIとコミュニティの力でなくす。無料セミナー、学生コミュニティ、オープンな学習コンテンツを通じて、誰もがAIの恩恵を受けられる世界を目指します。

「学びたい」という意志さえあれば、誰でもAIを使いこなせるようになる環境を提供し続けます。

CORE VALUE 01

関わるすべての人に「良かった」を。

妥協しない。速さよりも、本当に良いものを。

品質が信頼をつくり、信頼が次の挑戦をつくる。PLaiが生み出すすべてのプロダクト、すべてのコミュニケーションに、この基準を置く。

顧客・パートナー・コミュニティ・社員──関わるすべての人が「PLaiと組んでよかった」と言える瞬間を、毎日積み重ねます。

CORE VALUE 02

たった一人の「ありがとう」のために発信する。

ビジネスの本質は「ありがとう」の交換。

お客様、仲間、コミュニティ。すべての接点で感謝を生む仕事をする。テクノロジーの力で、一人ひとりの「ありがとう」を最大化する。

フォロワー数や売上の前に、「誰かのありがとうを引き出せたか」を毎日問い続けます。

CORE VALUE 03

リスクに怯えるより、人生を賭ける価値に賭ける。

失敗を恐れず、挑戦し続ける文化を持つ。

リスクを取らなければ、次のステージには行けない。現状維持は後退と同じ。AIという波に乗り、常に次の一手を打ち続ける。

新しい事業、新しい技術、新しい仕組み──毎月のように「初めて」をつくる組織でありたい。
